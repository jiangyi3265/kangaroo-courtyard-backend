`kg-license-watermark.ttf` is a static, seven-glyph subset of Noto Sans SC at weight 600, renamed KG License Watermark. It is bundled to render “仅用于袋鼠认证” consistently on headless servers without relying on installed Chinese fonts.

Source: the project's existing `artifacts/jobs-detail-calibration-20261024/NotoSansSC-source.ttf`. Copyright and SIL Open Font License are preserved in `kg-license-watermark-OFL.txt` and in the font's name table. No other font glyphs are included.
